事業の目的
要介護状態（介護予防にあたっては要支援状態）にある利用者が居宅において、その有する能力に応じて、自立した日常生活を送ることができるよう、利用者の日常生活上の便宜を図り、介護者の負担の軽減を図れるよう適切な福祉用具（介護予防福祉用具）貸与を提供することを目的とします。

運営方針

  1. 運営にあたっては、介護保険法並びに関連する法律の趣旨及び内容に沿ったものとします。
  2. 福祉用具の選定にあたっては、利用者の心身の状況、希望及びそのおかれている環境を踏まえた上で適切な援助をします。
  3. 常に清潔かつ安全で正常な機能を有する福祉用具を貸与します。
  4. 提供したサービスの質の評価を行い、その改善に努めます。
  5. サービスの提供にあたっては、研修等により専門相談員の資質向上に努めます。

職員体制　管理者1名（常勤、福祉用具専門相談員兼務）／福祉用具専門相談員6名（常勤1名は管理者兼務、常勤4名、非常勤1名）

その他の取得資格：福祉住環境コーディネーター2級、訪問介護員2級

3. 提供するサービスの内容及び費用について

サービスの流れ　福祉用具の選定・貸与計画 → 搬入・組立 → 調整・説明・指導 → アフターサービス（6か月ごとに利用状況を確認） → 搬出

福祉用具貸与計画の作成　利用者の日常生活や心身の状況及び希望を踏まえ、居宅サービス計画（又は介護予防サービス計画）の内容に沿って福祉用具貸与計画を作成します。作成に当たっては、その内容を利用者に説明し、同意を得たうえで交付します。

実施状況の把握　計画作成後、実施状況の把握（モニタリング）を行い、結果を踏まえ必要に応じて計画を変更します。モニタリングの結果は担当の指定居宅介護支援事業者（又は地域包括支援センター）に報告します。

基本料金　利用者負担金は当事業所のレンタル料金表によるものとし、原則サービスに要した費用の1割（一定以上の所得のある方は2割又は3割）の額となります。

利用開始又は終了の時期利用料
開始日が開始月の15日以前1か月の全額
開始日が開始月の16日以降1か月の1/2の額
終了日が終了月の15日以前1か月の1/2の額
終了日が終了月の16日以降1か月の全額
利用開始月と終了日が同月1か月の全額

※介護保険給付の支給限度額を超えてサービスを利用する場合、超えた額の全額（10割）をご負担いただきます。

貸与と販売の選択制　選択制の対象福祉用具については、貸与または販売のいずれかを利用者が選択できることについて、メリット・デメリットを含め十分説明を行い、必要な情報を提供し、医師や専門職の意見、身体状況を踏まえ提案します。利用開始後6月以内に少なくとも1回モニタリングを行い、貸与継続の必要性を検討します。

その他費用　遠距離・山間・離島等への搬入出時の交通費／特別な作業や措置（クレーン使用等）が必要な場合や転居等による移動の搬出入費

支払方法　口座引き落とし（翌月27日、郵便局は月末）／銀行振込（翌月末まで）／現金払い（翌月末まで、集金対応可）

延滞　正当な理由なく支払期日から2か月以上滞納し、督促から14日以内に支払が無い場合は契約を解除のうえ未払い分をお支払いいただきます。

キャンセル　搬入日の前日までにご連絡がない場合はキャンセル料をいただく場合があります。ただし容態の急変など緊急やむを得ない事情がある場合は不要です。連絡先：084-971-8882

4. 衛生管理等について

従業者の清潔の保持及び健康状態について必要な管理を行います。回収した福祉用具は種類・材質等からみて適切な消毒効果を有する方法により速やかに消毒し、消毒済みのものと未消毒のものを区分して保管します。

  4. 納品担当者の取扱説明通りの機能が発揮されない場合。

第6条（物件の使用）

（1）乙は、物件を、別表2記載の使用場所で、善良な管理者の注意をもって使用、保管し、また、同様の注意をもって使用者に使用させるものとします。

乙は、乙の住所または使用者の住所あるいは別表2記載の使用場所を変更したときは遅滞なくその旨甲に通知します。

消費税及び地方消費税（以下「消費税等」という）は乙が負担し、レンタル料とともに甲に支払います。

第10条（物件の滅失、毀損）

第4条に基づく物件の引渡から第16条に基づく物件の返還が完了するまでの間に、乙または使用者の故意もしくは過失により物件が滅失（修理不能の場合を含む。以下同じ。）または毀損したときは、乙は甲に対し、その損害を賠償するものとします。

第11条（使用者に対する免責）

使用者に次の事由に基づく事故または損害が発生した場合は、甲及び所有者は責任を負わないものとします。

  1. 物件の使用を原因としない使用者の急激な体調の変化等、使用者の身体に関する不測の事態に起因して事故が発生した場合。
  2. 使用者及びその家族による、甲または甲の従業員の指示・依頼に反する行為または物件の取扱説明に反した使用、あるいはこれらの者の不実の告知に起因して事故が発生した場合。
  3. 地震、噴火等の天災、公権力の行使等、甲及び所有者の責によらない事由に起因して事故が発生した場合またはレンタル契約が継続不可能となった場合。

第12条（損害賠償）

（1）乙が、レンタル料の支払いを怠るなど、この契約の条項に違反した場合で、相当の期間を設けてその是正を催告したにもかかわらず是正されないときは、甲は、通知のみでこの契約を解除することができ、この契約が解除されたときは、乙は物件を甲に返還し、併せて甲に対する未払レンタル料その他の金銭債務全額を支払います。

第15条（契約の終了）

  1. 使用者が死亡した場合。
  2. レンタル期間中に物件が滅失したとき。

第16条（物件の返還）

（1）この契約がレンタル期間の満了、解除、解約その他の理由により終了したときは、乙は直ちに物件を甲に返還します。
